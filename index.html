PingCue Privacy Policy

Effective date: October 10, 2026
Applies to: PingCue for Android, version 1.x

PingCue creates local follow-up reminders for notifications the user identifies as important. Notification content can be sensitive, so PingCue is intentionally built without an account, advertising, analytics, or a cloud backend. This policy applies to PingCue and its publisher, RADIVUM.

Notification access

If you enable Android Notification Access for PingCue, Android allows the app to receive notifications posted on your device. PingCue uses that access only to:

  • identify the source application;
  • read notification fields exposed by Android, such as title, message text, sender or conversation label where available, notification identifier, tag, key, and timestamp;
  • check whether you enabled monitoring for that source app;
  • evaluate your active on-device rules; and
  • store a matching item and schedule the reminders you configured.

Before reading notification content, PingCue checks the source app locally. If you have not enabled that app for monitoring, PingCue ignores the notification without opening its title, message text, sender, or other notification fields. PingCue also ignores its own reminder notifications. You can disable Notification Access at any time in Android Settings. When access is disabled, PingCue cannot capture new source notifications; existing local items and settings remain until you delete them or retention removes them.

PingCue requires your affirmative agreement to its current in-app disclosure before monitoring selected-app notifications in the background, including while the app is closed or the screen is locked. Agreement is saved locally. Android access alone does not enable monitoring; changed disclosures require agreement again. Stop monitoring in Settings or with the monitoring notification's Stop action. Android security lockdown deletes all captured notification history, schedules and reminder activity, plus automatically learned conversation names. Manually configured rules and selected apps remain.

Installed-app picker

When you open PingCue's app picker, it reads the local package names, display names, and icons of launchable apps so you can choose which sources to monitor. This list is used only to show the picker on your device. It is not transmitted, shared, used for advertising, or stored except for the apps you explicitly select to monitor.

Contact picker and conversations

PingCue does not request broad Android Contacts permission. When you choose a phone contact for a WhatsApp rule, Android's system contact picker provides only the contact you select so PingCue can use its display name as a local rule filter. It does not read the device address book, phone numbers, email addresses, photos, notes, or account credentials.

WhatsApp does not expose its private contacts or groups database to other apps. Conversation or group display names are learned only from notifications for apps you explicitly enable for monitoring, or entered manually by you. Contact and conversation names are never transmitted off the device.

Data processed and local storage

PingCue processes and may store the following in the app's private Android storage:

  • package names and display names of apps you explicitly monitor; the broader launchable-app list is only queried while the picker is open and is not stored;
  • rule names, keywords, exclusion keywords, priority, timing, and repeat settings;
  • selected contact or group display names and locally detected WhatsApp conversation names;
  • matched notification title, message, sender where exposed, source app, notification identifiers, timestamps, matched rule or keyword, status, and reminder activity; and
  • preferences such as theme, default reminder and snooze settings, quiet hours, and history retention.

This data is not transmitted to RADIVUM or a third-party server. The Android manifest does not request Internet access. PingCue does not include analytics, advertising, crash-reporting, authentication, or cloud SDKs.

Data sharing and sale

PingCue does not sell notification data or share it with third parties. Selecting Open asks Android to launch the source app already installed on your device; PingCue does not send stored notification content to that app.

Retention and deletion

The default notification-history retention is 30 days. You may choose 7 days, 30 days, 90 days, or forever. Retention cleanup deletes completed or ignored history items only; an active reminder remains until you cancel or disable monitoring. Snoozing postpones a reminder and retains its captured content.

Settings provides two deletion controls:

  • Delete notification history removes captured notification content, reminder schedules, and reminder activity while leaving rules and monitored-app choices.
  • Delete all local data removes rules, monitored apps, captured notification content, schedules, activity, and preferences and returns PingCue to first-run state.

Uninstalling PingCue also causes Android to remove its private application data. PingCue disables cloud backup and excludes its database and preferences from device transfer.

Permissions and special access

  • Notification Access is special Android access used for the core monitoring and matching function described above.
  • Post notifications allows PingCue to show follow-up reminders on Android 13 and later.
  • Android's contact picker is optional and supplies only a display name you explicitly select for a contact-specific WhatsApp rule; PingCue does not request broad Contacts permission.
  • Modify audio settings lets PingCue temporarily raise the alarm audio stream while a reminder ringtone is playing. If the user has not changed it during the alarm, PingCue restores the previous alarm volume when playback ends; it does not change the phone's ringer mode.
  • Foreground service and wake lock keep user-enabled background monitoring and an active reminder reliable. A silent ongoing monitoring notification is shown while monitoring is enabled.
  • Receive boot completed allows persisted pending reminder work to be restored after reboot.
  • Vibrate allows reminder channels to use user-controlled vibration behavior.

PingCue does not request location, camera, microphone, SMS, call logs, broad file access, accessibility, or exact-alarm permission.

Notification previews

In PingCue version 1.2.29 and later, notification previews are hidden by default in Home, History and search, and in reminder notifications. Only explicitly enabling Show title and message for the current matching rule reveals captured content; missing or deleted rules keep it hidden. Turning previews off hides existing history too, without deleting stored items.

Security

Data is stored in Android app-private storage and is protected by Android's application sandbox and device security controls. Reminder notifications use private lock-screen visibility and a generic public version. PingCue does not claim that local data is separately end-to-end encrypted. Users should protect their device with a secure screen lock and use Android's notification privacy controls.

Children

PingCue is a general productivity utility and is not directed to children. It does not knowingly collect or transmit personal data to the publisher.

Changes to this policy

If the implementation, permissions, dependencies, or data practices change, RADIVUM will update this policy and its effective date before distributing the affected release. Material new uses of sensitive data require an updated in-app disclosure and user consent where applicable.
